## Optional presentation packages

| Package | Required for unversioned sync | Purpose |
| --- | --- | --- |
| DocsPress theme | No | A documentation-focused Site Editor experience |
| DocsPress Blocks | No | Rich documentation blocks |

The Blocks plugin is required when API versioning is enabled. For ordinary Markdown made of portable content, the active WordPress theme and core blocks are enough.
